# SafeMotion 三版完整对比报告

> codex / deepseek / kimi 三个 agent 独立实现的 VLA 机械臂安全执行器。
> 测试人员视角 · 本地黑盒测试 · 同一批 100 组随机数据（seed=556800785）。

---

## 一、三版一句话定位


| 版本         | 定位                                                               |
| -------------- | -------------------------------------------------------------------- |
| **codex**    | 最完整、0 bug、架构清晰，可直接提交的「均衡型」                    |
| **deepseek** | 完整度中等，但有一个 crash bug 且关节越界策略与另两版相反          |
| **kimi**     | 算法最精细（二分+子步+三层防线），但外围（测试/文档/场景）几乎为空 |

## 三、核心实现逐项对比

### 1. UR5 正运动学（三版都正确）


|          | codex       | deepseek      | kimi                                       |
| ---------- | ------------- | --------------- | -------------------------------------------- |
| DH 约定  | 标准 DH     | 标准 DH       | 标准 DH                                    |
| 返回     | OrderedDict | (8,3) 数组    | dict + points                              |
| 附加常量 | —          | link_segments | NODE_LABELS / LINK_SEGMENTS / LINK_LENGTHS |

三版都用题目给的标称 DH，FK 结果一致（都验证过 real 场景 margin≈0.039）。

### 2. 全身安全空间检查（关键差异）


|          | codex                              | deepseek               | kimi                      |
| ---------- | ------------------------------------ | ------------------------ | --------------------------- |
| 方法     | **凸集性质：只查节点，不采样**     | 连杆采样（2cm）        | 凸集 + 采样兜底           |
| 数学依据 | 凸盒内端点在内 ⟹ 整段在内（精确） | 采样近似（需说明误差） | 凸集精确 + 采样防浮点边界 |

- codex 最优雅（省去采样，且注释写清了凸集推理）；kimi 兼顾精确与防御；deepseek 纯采样（题目允许但需额外说明采样误差）。

### 3. 输入检查（deepseek 有 bug）


|              | codex           | deepseek               | kimi                     |
| -------------- | ----------------- | ------------------------ | -------------------------- |
| 检查时机     | 所有计算之前 ✅ | **dt 计算在检查前 ❌** | 所有计算之前 ✅          |
| 关节目标越界 | 拒绝            | **钳位**               | 拒绝                     |
| 错误信息     | 精确到关节      | 较粗略                 | 精确到「第几点第几关节」 |

### 4. 安全过滤算法（kimi 最强）


|             | codex     | deepseek | kimi                   |
| ------------- | ----------- | ---------- | ------------------------ |
| 速度缩放    | 固定档位  | 固定档位 | 固定档位 +**二分细化** |
| 子步检查    | **10** 步 | 无       | 4 步                   |
| fail-closed | ✅        | ✅       | ✅ + step 前独立复核   |

### 5. Mock Robot / Replay

- Mock Robot：三版一致（题目一阶积分模型）。
- Replay 防御深度：codex 有 **post-execution invariant check**（执行后复核，独有）；kimi 有 **step 前独立复核**；deepseek 无额外复核。

## 六、每版亮点与硬伤

### codex ✅✅

- **亮点**：凸集精确几何检查；post-execution 深度防御；7 测试 + 5 场景 + README + 面试指南；0 bug。
- **短板**：无二分细化（越界干预粒度粗）；`max_joint_velocity=1.5` 偏保守（非缺陷，是选择）。

### deepseek ⚠️

- **亮点**：完整度中等（6 测试 + README）。
- **硬伤**：`action_hz=0` 崩溃（输入检查时机错误）；关节越界「钳位」与题目第 3 节「非法输入不得进入 Mock Robot」存在解释风险；无子步检查、无二分。

### kimi ⚠️

- **亮点**：二分细化 + 子步 + 三层防线（安全过滤满分水准）；--explain；错误信息最精确；凸集+采样兜底。
- **硬伤**：**完全无测试/README/自建场景**（题目 15 分测试 + 5 分文档 = 20 分直接空缺）。

## 八、综合结论

1. **安全性核心**：三版在随机数据上 0 违规，安全过滤逻辑都正确。
2. **唯一功能性 bug**：deepseek 的 `action_hz=0` 崩溃。
3. **最优提交 = codex 基底 + kimi 的二分细化（+ 可选 --explain / nominal_margin）**。
4. deepseek 版不并任何东西。
